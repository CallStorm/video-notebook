# 功能说明

按能力点介绍**当前实现**。产品原文见 [requirements.md](requirements.md)。

## 笔记本与来源

- **笔记本**：创建 / 列表 / 置顶 / 删除；打开后三栏（来源 · 对话 · Studio）。
- **来源**：本地上传视频；粘贴 URL（YouTube / 直链媒体等，经 yt-dlp 或 httpx）。
- **字幕链**：内嵌字幕 → 平台字幕 → ASR；失败可在卡片上重试 / 重新生成。
- **概览**：用默认 LLM 生成；若模型侧内容安全拦截，属模型审核而非抓取失败。

Cookie / 代理在 **后台 → 抓取与网络** 按平台配置（Netscape Cookie）。

## 对话

- 仅使用左栏**勾选**的来源全文作为上下文。
- 另附最近 N 轮对话历史；N 可在管理后台配置。上下文不够时**先砍历史，不砍勾选来源**。
- 回答可带来源引用；支持保存为笔记、复制、相关问题。

## Studio

- **思维导图**、**幻灯片**（PPT）：选语言 / 来源 / 主题后入队生成。
- 由 `studio` 队列 Worker 执行；依赖 Claude CLI（本机或挂载进容器，见 [deployment.md](deployment.md)）。
- Skills / Agents 可在后台管理。

## 发现与聚合搜索

- **发现**：站内笔记本范围（全部 / 我的 / 公开）；支持关键词与语义检索（Qdrant）。
- **聚合搜索**：按平台 Tab（全部 / B站 / YouTube）搜视频并入库分析（复用抓取流水线）。

## 集合与权限

- **集合（Collections）**：把多个笔记本归组；列表 / 详情 / 加入集合。
- **账号**：管理员后台创建；手机号 + 密码登录；角色分普通用户 / 管理员。
- **外观**：浅色 / 深色 + 多套皮肤（`data-skin`），设置里可切换。

## 管理后台

- 模型配置（LLM / ASR）、抓取与网络、向量库地址、账号、对话保留轮数等。
- 健康检查：`GET /api/health`、`GET /api/health/ready`。
