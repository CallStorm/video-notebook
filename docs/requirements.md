# 产品需求（现行）

> 以当前代码与产品行为为准。旧版「集合」等需求已废弃。能力说明见 [功能说明](features.md)，采集见 [采集说明](collection.md)。

## 定位

内部使用的视频知识工作台：把视频入库、出字幕，支持对话、标签整理、知识底稿，以及思维导图 / 幻灯片 / 阅读页。

## 范围（v1 现行）

| 能力 | 说明 |
|------|------|
| 笔记本 | 作者自有；可公开到「发现」只读 |
| 来源 | 上传、URL 抓取（含抖音分享链接）、网页搜索加片（B 站 / YouTube） |
| 字幕 / 概览 / 索引 | media-worker 异步 |
| 对话 | 勾选来源问答，引用跳字幕 |
| 标签 | 多对多；Chip；管理；AI 自动整理 |
| 知识底稿 | 策略抽点 → 导图 / 幻灯片 / 阅读页；来源仍在抓取或字幕未就绪时，对外 Agent 拒绝生成 |
| 发现 | 关键词 + 语义 |
| 账号 | 管理员开户，无自助注册 |
| 微信小程序 | 手机收集入口（分享抽链）；走 Agent API；内网/体验版 |
| 对外 Agent | Skill + MCP；Token 在设置 → Agent 接入创建（`vn_agent_…`）；先搜索再停步 |
| 后台 | 模型、网络、向量、策略、观测 |

## 明确不做（当前）

- 集合（Collections）
- 抖音关键词搜索
- 多人实时协作、受邀协作者
- 用户自助注册 / 短信

## 非功能

- 本地优先部署（见 [development.md](development.md)）
- 密钥与 Cookie 可落库加密；主密钥见 `.env` 的 `MASTER_SECRET`
- 异步任务经 Celery，避免阻塞 API
