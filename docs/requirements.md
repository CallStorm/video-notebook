# 产品需求（现行）

> 以当前代码与产品行为为准。旧版「集合」等需求已废弃。

## 定位

内部使用的视频知识工作台：把视频入库、出字幕，支持对话、标签整理、知识底稿，以及思维导图 / PPT 产物。

## 范围（v1 现行）

| 能力 | 说明 |
|------|------|
| 笔记本 | 作者自有；可公开到「发现」只读 |
| 来源 | 上传、URL 抓取、网页搜索加片（B 站 / YouTube） |
| 字幕 / 概览 / 索引 | media-worker 异步 |
| 对话 | 勾选来源问答，引用跳字幕 |
| 标签 | 多对多；Chip；管理；AI 自动整理 |
| 知识底稿 | 策略抽点 → 导图 / PPT |
| 发现 | 关键词 + 语义 |
| 账号 | 管理员开户，无自助注册 |
| 后台 | 模型、网络、向量、策略、观测 |

## 明确不做（当前）

- 集合（Collections）
- 抖音搜索 / 抓取
- 多人实时协作、受邀协作者
- 用户自助注册 / 短信

## 非功能

- 本地优先部署（见 [development.md](development.md)）
- 密钥与 Cookie 可落库加密；主密钥见 `.env` 的 `MASTER_SECRET`
- 异步任务经 Celery，避免阻塞 API
