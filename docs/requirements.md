# 视频知识工作台 · 需求说明

根据 Gemini Notebook 整理

## 首页

- 顶部有三个入口：我的笔记本、发现、集合。旁边可以搜索笔记本，可以在网格和列表之间切换。
- 「发现」是后续多人共享的入口。当前先做占位，打开是空页面。
- 「我的笔记本」里，右上角是「新建笔记本」。
- 每张卡片有图标、标题、日期、来源数量，以及一个更多菜单（修改 title、置顶、添加到集合、删除）。鼠标停在卡片上，会看到完整标题。点卡片进入笔记本。

## 集合

- 集合是单独一页，右上角是「新建集合」。
- 每张集合卡片有图标、名称、里面有几个笔记本，以及一个更多菜单（编辑、删除、图标）。

## 笔记本

打开后是三栏，顶栏是笔记本标题，以及新建笔记本。

### 左栏：来源

这里的文件就是视频。当前链接和上传都只支持视频。

- 添加来源：弹出一层。可以上传视频、贴视频网页（含 YouTube）、粘贴文字，也可以把视频文件拖进去。
- 创建笔记：点击创建，在右侧工作室显示编辑界面，可以写富文本。创建完成后，笔记进入左栏列表。

添加后，下面列表分成视频列表和笔记列表。每一条有三部分：

- logo：视频或笔记的图标
- 文件名
- checkbox。默认选中。问答和右侧工作室二次加工时，只用勾选中的来源。

点名称：

- 点的是视频：左栏上方显示概览，下方显示这条视频的字幕。
- 点的是笔记：在右侧工作室区域下方显示笔记内容。

### 中栏：对话

- 输入框是「提问，或让它生成点什么」。下方标出这次用了几个来源。
- 回答按资料来写，句中带编号。
- 鼠标悬浮在编号上，可以预览相关内容。
- 点击引用编号，左栏自动显示该来源的概览和下面的内容，并定位到相关位置。
- 回答下面有保存到笔记、复制。保存后的笔记进入左栏列表。
- 下面可以生成三个相关问题。

### 右栏：工作室

上面是一排生成入口：幻灯片、思维导图。下面是已经生成的结果列表。正在生成的可以删除。

## 思维导图

- 在工作室点击思维导图，弹出页面。可以选择语言、来源、主题，然后点击生成。来源列表默认带上左栏已勾选的来源。
- 工作室下方可以看到思维导图任务。生成好后可以点击打开。
- 打开后：
  - 左侧可以放大、缩小、全部展开、下载。左上角可以查看用到的来源。
  - 右上角可以展开，铺满屏幕。更多操作里可以删除。
  - 中间的图，点箭头展开或收起。点文字，会把问题发到对话里。导图保持打开。
  - 有父节点时：`Discuss what these sources say about {当前节点}, in the larger context of {父节点}.`
  - 没有父节点时：`Discuss what these sources say about {当前节点}.` 例如：`Discuss what these sources say about 灭佛之源：战争储备、财政危机与皇权神权.`
- 思维导图名称每次自动生成。

## 幻灯片

- 在工作室点击幻灯片，弹出页面。可以选择语言、来源，并描述想创建的幻灯片，然后点击生成。长度由 AI 判断，并给出一个建议长度。
- 生成好的幻灯片可以在右栏里滚动查看，也可以像思维导图那样展开铺满。
- 右上角更多菜单可以下载 PPT、PDF，或删除。
