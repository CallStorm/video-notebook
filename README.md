# 视频笔记本

从视频里学习和吸收知识。把一条片子收进笔记本，看清它讲了什么，再变成以后找得到、问得了、用得上的内容。

<img alt="笔记本列表" src="docs/images/home.png" width="760" />

## 核心能力

**多端接入。** 同一套笔记本，可以从 PC 网页、对外 Agent 和微信小程序使用。

**分析。** 抓取字幕和概览，按勾选的来源对话，引用回到字幕时间点；再生成知识底稿，以及思维导图、幻灯片和阅读页。

**采集。** 哔哩哔哩和 YouTube 可以按关键词搜索后加入；这两个站点加上抖音，也可以直接用链接入库。
