# 影知 · Videnote

把视频变成可检索、可对话、可产出的知识笔记本。品牌：**影知** / **Videnote**。

同一套后端和笔记本数据，从三条入口使用：**PC 网页**、**对外 Agent**、**微信小程序**。各端能做什么、怎么接，见 [功能说明](docs/features.md)。
